CHAI EMPIRE — ANDROID/PWA PROJECT

This folder contains the PWA-ready version of your original game.

Files:
- index.html: your game
- manifest.json: install/app metadata
- service-worker.js: basic offline caching
- icons/: app icons

Next: upload these files to a public GitHub repository and enable GitHub Pages. Then test the HTTPS URL in PWABuilder. The Android package generated by PWABuilder is intended for Android devices; it cannot be installed on iPhone.

Note: Game saves use browser localStorage on each device/browser. They do not automatically sync between devices.
